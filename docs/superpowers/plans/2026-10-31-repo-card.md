# Milestone 3.5: Repo Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a project can show a branded card with its latest release in its readme, and the chamoji Action keeps that card current on every release tag and once a day.

**Architecture:**

- **The renderer** is `GET https://chamoji.dev/api/card` in the private `chamoji-web` repo. It turns validated query parameters into a 1200 × 400 PNG. It has no database and no GitHub token, and it stores nothing.
- **The stats** come from `chamoji card`, which reads the local git history through `buildChangelog` and prints the renderer URL.
- **The Action's `card` mode** downloads that URL and saves the image as `card.png` on a separate branch, `chamoji-card`. The branch holds one commit, replaced on each change, so daily runs don't grow the repository.
- **The readme** shows `https://raw.githubusercontent.com/<owner>/<repo>/chamoji-card/card.png`, an address that never changes.

**Tech stack:** Next.js 16 route handler with `next/og` and vitest in `chamoji-web`. TypeScript, meow, vitest and bash 3.2 in `chamoji-ai`.

**Spec:** `docs/ROADMAP.md`, milestone 3.5.

**Repos:** Tasks 1–2 are in `chamoji-web`, on a branch named `feat/repo-card`. Tasks 3–7 are in `chamoji-ai`, on `feat/repo-card`.

## Global constraints

- **Licensed files:** the fonts and art stay in `chamoji-web`. Nothing from them goes into `chamoji-ai`.
- **What leaves the repository:** only the repo name, latest tag, its date and counts. No commit text, author or file name goes to the renderer. A test pins this.
- **No AI:** `chamoji card` never classifies, so "sorted" means sorted by rules alone. It ignores `CHAMOJI_AI` and `--ai`.
- **Opt-in:** `auto` mode never picks `card`. Existing modes don't change.
- **The Action:** bash 3.2, and inputs arrive as environment variables, never as `${{ }}` pasted into the script.
- **Force-pushing:** only to a branch that doesn't exist or holds exactly `card.png`.
- **A decoration can't break a release:** a renderer that's down or returns something else gives a warning and exit code 0, and the last card stays.
- **Commits** use gitmoji and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review focus

1. **A very long repo name.** It stays on one line inside the card and shows an ellipsis. Covered in Tasks 1 and 2.
2. **A repo with no tags.** The card says "No releases yet" and still shows its commit stats. Covered in Tasks 1, 2 and 3.
3. **The renderer is down, or returns an HTML error page with status 200.** Nothing is saved, the job passes with a warning, and the last card stays. Covered in Task 5.
4. **`card-branch` set to a real branch, such as `main`.** The Action refuses and changes nothing. Covered in Task 5.
5. **A tag run, where the checkout is a detached HEAD.** The card is saved, and HEAD, the index and the working tree are untouched. Covered in Task 5.

- [ ] **Step 3: Add the `card` case to `action/run.sh`**

Call the CLI through `"${cli[@]}"` rather than the `chamoji` function, so `--ai` is never added. The order matters:

```bash
card)
	branch=${CHAMOJI_CARD_BRANCH:-chamoji-card}
	repo=${GH_REPO:-${GITHUB_REPOSITORY:-}}
	git check-ref-format --branch "$branch" >/dev/null 2>&1 || fail "card-branch isn't a branch name: $branch"
	url=$("${cli[@]}" card --repo "$repo" --endpoint "${CHAMOJI_CARD_URL:-https://chamoji.dev/api/card}" --no-update-check)
	image="$work/chamoji-card.png"
	# curl --fail --silent --show-error --location --retry 2 --max-time 30 --output "$image" "$url"
	# On failure, or when the first 8 bytes aren't 89504e470d0a1a0a:
	#   echo a ::warning:: line, then exit 0.
	current=
	tip=
	if git ls-remote --exit-code --heads origin "$branch" >/dev/null 2>&1; then
		git fetch --quiet --no-tags origin "+refs/heads/$branch:refs/chamoji/card"
		# Fail, naming the branch, unless `git ls-tree --name-only` is exactly card.png.
		tip=$(git rev-parse refs/chamoji/card)
		current=$(git rev-parse refs/chamoji/card:card.png)
	fi
	blob=$(git hash-object -w --no-filters "$image")
	# If $blob equals $current, say so, write the output and exit 0.
	tree=$(printf '100644 blob %s\tcard.png\n' "$blob" | git mktree)
	# commit-tree with no parent, as github-actions[bot], set through GIT_AUTHOR_* and GIT_COMMITTER_*.
	# git push --force-with-lease="refs/heads/$branch:$tip" origin "$commit:refs/heads/$branch"
	# (an empty $tip means the branch must not exist yet; the lease makes the push refuse if it changed since we looked)
	# On failure: fail "couldn't push to $branch; it changed during this run, or the job needs contents: write".
	# Write card-url to $output.
	;;
```

Don't use `git config`, a worktree or `--depth`: each one would change the checkout or make it shallow for later steps.

Add `card` to the header comment, the `unknown mode` message and the `auto` failure message.
